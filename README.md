# Purple Sign In UI – Flutter

A clean sign in screen with purple corner shapes, built with Flutter.

## Run it

```bash
flutter pub get
flutter run
```

## Files

- `lib/main.dart` – app entry point
- `lib/sign_in_page.dart` – the sign in screen
- `lib/sign_in_widgets.dart` – colors, corner blobs, text fields, button and links

## Packages

- [google_fonts](https://pub.dev/packages/google_fonts) – Outfit font
